# C4_management_view

ABN Amro Intern project.

During the Corona period a lot of Developers quited their job at the ABN. They discovered that every time a colleague leaves, part of the software knowledge system also disappears. Only a limited amount of software information was stored, and the information that had already been saved was difficult to access. This made it very difficult for new developers to collaborate on systems. This is why they decided to work on a C4 model.

We have been commissioned to make this application accessible for Android. The application is intended for managers to oversee the architectural system. The C4 model contains layers with elements within those layers. Elements are compatible across teams working on the element. 

In this project I am working on the team management part so that teams can be compatible. So this is a CRUD system for the team which further provides the ability to view user information about a specific team member. There will be a search functionality for looking up users (to create a team) and searching for a team. I implement the front/backend for this.
